# Wrestling-clash

مشروع لعبة مصارعة ثلاثية الأبعاد للهواتف، يجري تطويره باستخدام Unity 2022.3 LTS.

## محتويات المستودع

- `UnityProject/`: مشروع Unity والسكريبتات وإعدادات Android.
- `RingClash3D_Unity.zip`: أرشيف الأصول الأصلية ومكتبات الحركات.
- `ANIMATION_AUDIT_AR.md`: ملخص تدقيق مكتبات الحركات.
- `THIRD_PARTY_LICENSES.md`: سجل التبعيات والأصول الخارجية وحقوق استخدامها.
- `LICENSE`: ترخيص MIT للكود والتوثيق الأصليين المملوكين للمساهمين فقط.

## مهم قبل نشر اللعبة

**ترخيص MIT لا يشمل نماذج المصارعين أو الحركات أو الخامات أو أي أصول خارجية.**

وثائق المصدر تصف نموذجي AJ Styles وRandy Orton المرفقين بأنهما للاستخدام الشخصي/التعليمي للطلاب فقط. كما أن حقوق إعادة توزيع مكتبات WWE2011 ومقاطع Mixamo وبعض النماذج الأخرى لم تُحسم بعد.

لذلك لا تعتبر النسخة الحالية مصرحًا بنشرها للعامة أو بيعها قبل مراجعة
[سجل الأصول والتراخيص](THIRD_PARTY_LICENSES.md)، والحصول على الأذونات اللازمة
أو استبدال الأصول المقيدة بأصول تسمح تراخيصها بالاستخدام المقصود.

## بناء Android

يوجد Workflow لبناء APK يدويًا في
[`.github/workflows/build-android-apk.yml`](.github/workflows/build-android-apk.yml).
يتطلب إعداد بيانات ترخيص Unity في GitHub Actions Secrets. نجاح فحوصات الأرشيف
أو تغليف المشروع لا يعني أن APK تم بناؤه أو اختباره على هاتف.
