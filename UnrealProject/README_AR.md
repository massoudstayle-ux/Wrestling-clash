# Wrestling Clash — Unreal Engine

هذه نسخة Unreal مستقلة عن مشروع Unity الموجود في المجلد `UnityProject/`. لا تحذف أو تعدّل ملفات Unity عند العمل على هذه النسخة.

## الحالة الحالية
- يوجد هيكل C++ أولي للمشروع.
- أضيف ممثل حلبة مؤقت: منصة مربعة وأعمدة وحبال هندسية بسيطة.
- أضيفت شخصية لاعب مرئية مؤقتة مكوّنة من أشكال هندسية، مع حركة WASD وقفز ودوران بالكاميرا.
- أضيف Game Mode لإنشاء الحلبة ومصارع خصم ثابت للاختبار.
- لم يتم تضمين ملفات Unreal Engine الثنائية أو أصول فنية أو شخصيات نهائية.
- أضيف نظام أولي جداً للصحة والضرر ومدى اللكم والركل، دون رسوم حركية أو ردود فعل بعد.
- لم يتم تشغيل Unreal Editor أو اختبار البناء؛ لذلك لا نؤكد أن المشروع يبني أو يعمل حتى الآن.
- إعداد Android وتصدير APK مؤجلان حتى نجاح بناء واختبار المشروع على جهاز متوافق.

## التحكم الأولي
- W / A / S / D: الحركة.
- Space: القفز.
- J: لكمة أولية.
- K: ركلة أولية.
- Mouse: تدوير الكاميرا.
- الخصم ثابت حالياً؛ الضرر تجريبي ويظهر على الشاشة أثناء الاختبار.

## خطة التطوير
1. فتح المشروع والتحقق من البناء في إصدار Unreal محدد.
2. إنشاء مستوى اختبار وحلبة ذات خامات وإضاءة مناسبة.
3. إضافة شخصيتي Runner وBoxer ونماذج ورسوم متحركة مرخصة.
4. إعداد كاميرا مباراة وتحكم لمس للهاتف.
5. إضافة نظام القتال والحركات والاصطدامات.
6. إعداد Android packaging بعد نجاح اختبار سطح المكتب.

## العمل من المتصفح
الرابط الذي ينتهي بـ `github.dev` يفتح محرر VS Code داخل المتصفح لتحرير الملفات ومراجعتها، لكنه لا يوفر Terminal أو جهاز بناء مثل Codespaces، ولا يشغّل Unreal Editor ثلاثي الأبعاد. لا تعتبر هذه الملفات نسخة قابلة للتشغيل قبل بنائها واختبارها في جهاز متوافق مع Unreal. لا تعتبر هذه الملفات نسخة قابلة للتشغيل قبل فتحها بمحرك Unreal واختبارها.

## الرجوع عن هذه النسخة
كل التغييرات موجودة على الفرع `unreal/bootstrap`. للعودة إلى نسخة Unity الأصلية، اختر الفرع `main` في GitHub. لا تدمج هذا الفرع في main إلا بعد مراجعة التغييرات.
